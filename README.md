# মুসলিম টিউব — ডেক্সটপ (Windows / Linux)

অ্যান্ড্রয়েড অ্যাপের হুবহু ডেক্সটপ সংস্করণ: একই থিম (১৬টি), একই ফিল্টার/স্ক্রিনিং (`ContentFilter.kt`, `Screening.kt`), একই ট্যাব (হোম, শর্টস, মিউজিক, লাইব্রেরি, প্রোফাইল), NewPipeExtractor।
লাইসেন্স: GPLv3 (NewPipeExtractor-এর কারণে) — সোর্স পাবলিক রাখতে হবে।

## বিল্ড (GitHub Actions)
১. এই ফোল্ডারটা একটা GitHub রিপোতে আপলোড করুন (ফোল্ডারের ভেতরের ফাইলগুলো রিপোর রুটে)।
২. Actions ট্যাবে **Build Desktop** চলবে। শেষে Artifacts থেকে নামান:
   - `MuslimTube-windows-installer` (.msi) — ইনস্টলার
   - `MuslimTube-windows-portable` (.zip) — ইনস্টল ছাড়া চলে, `MuslimTube.exe`
   - `MuslimTube-linux-deb`
Windows বিল্ডে VLC ইঞ্জিন নিজে থেকেই ভেতরে জুড়ে যায়, আলাদা VLC লাগে না।
Linux-এ `sudo apt install vlc` লাগবে।

## নিজের পিসিতে চালাতে
JDK 17 থাকলে: `./gradlew run` (Windows-এ `gradlew.bat run`)। VLC ইনস্টল থাকতে হবে।

## কিবোর্ড
Esc = পেছনে, Space = চালান/থামান, ←/→ = ৫ সেকেন্ড, ↑/↓ = ভলিউম, F বা F11 = পুরো পর্দা, M = মিউট, ভিডিওতে ডাবল-ক্লিক = পুরো পর্দা।

## ডেটা কোথায় থাকে
Windows: `%APPDATA%\MuslimTube` (সংরক্ষিত, ইতিহাস, পছন্দ, ডাউনলোড করা ভিডিও)।

## ফোন সংস্করণ থেকে পার্থক্য
- ExoPlayer-এর বদলে VLC (libvlc); নিজস্ব কন্ট্রোল বার (সিক, ভলিউম, গতি, মান)।
- টেনে রিফ্রেশের বদলে 🔄 বোতাম; শেয়ারের বদলে "লিংক কপি"; PiP-এর বদলে অ্যাপের ভেতরের ছোট ভাসমান ভিডিও।
- চওড়া উইন্ডোতে ভিডিও বাঁয়ে, "আরও দেখুন" ডানে; গ্রিডে কলাম নিজে থেকে বাড়ে।
